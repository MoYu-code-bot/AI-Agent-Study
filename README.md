# AI大模型应用开发学习平台

一个面向 AI 大模型应用开发学习者的在线课程阅读平台，按照从基础概念到工程实战的路线组织内容，帮助学习者系统掌握 Prompt Engineering、模型接口调用、Embedding、RAG 等核心知识。

## 在线体验

- 访问地址：[AI大模型应用开发学习平台](https://moyu-code-bot.github.io/AI-Agent-Study/)
- 无需安装软件，使用现代浏览器即可开始学习。
- 推荐使用电脑或平板访问，以获得更完整的目录与内容阅读体验。

## 平台特色

- **结构化学习路线**：课程按阶段、章节和小节逐级组织，学习目标清晰，适合持续推进。
- **完整课程导航**：左侧目录支持展开、折叠和章节跳转，能够快速查看课程结构与当前位置。
- **全文关键词搜索**：可搜索 RAG、Embedding、LangChain 等关键词，并快速定位相关章节。
- **Markdown 风格阅读**：支持标题、段落、列表、表格、引用和代码块，兼顾知识讲解与技术示例。
- **代码语法高亮**：代码示例采用清晰的高亮样式，便于阅读、理解和复现。
- **章节学习闭环**：每节内容配有知识小结、练习题和实战任务，帮助完成“学习—检验—应用”的过程。
- **答题即时反馈**：提交练习题后会显示答题结果、正确答案及对应提示，便于及时纠正理解偏差。
- **学习进度记录**：已学习章节会自动记录，并通过整体进度直观展示学习情况。
- **阅读位置保持**：刷新页面后仍会停留在当前章节，减少重复查找。
- **夜间模式**：支持明暗主题切换，满足不同环境下的阅读需求。
- **响应式布局**：针对电脑和平板进行适配，在不同屏幕尺寸下保持良好的导航和阅读体验。

## 课程内容

当前课程围绕大模型应用开发的核心能力展开，主要包括：

1. **Prompt Engineering**
   - Prompt 基础与高质量提示词结构
   - Few-shot Prompt
   - Chain of Thought
   - Structured Output

2. **LLM API 开发**
   - 大模型接口基础
   - OpenAI API 调用
   - Qwen API 与 DeepSeek API 实战
   - Function Calling
   - 结构化输出与解析

3. **Embedding 与向量基础**
   - 文本向量化原理
   - 向量、相似度与语义搜索
   - Token 机制与使用成本

4. **RAG 检索增强生成**
   - RAG 基础与应用流程
   - 文档加载与文本切分
   - Embedding 入库与向量数据库
   - Retriever 检索器
   - Rerank 重排序

后续课程将继续覆盖 LangChain、Agent、LangGraph、企业级知识库和多智能体应用等方向。

## 学习方式

- **先理解概念**：按目录顺序阅读正文，掌握每节的核心原理和适用场景。
- **再完成小结**：通过章节小结快速回顾关键词、关键流程和注意事项。
- **及时练习**：提交练习题并根据反馈检查理解是否准确。
- **动手实战**：按照实战任务编写代码或设计方案，把知识转化为实际能力。
- **持续记录**：完成学习后标记章节，结合进度条规划后续学习。

## 技术特点

- 使用原生 HTML、CSS 和 JavaScript 构建，无复杂前端框架依赖。
- 课程内容与页面展示分离，便于持续补充和维护。
- 学习状态保存在当前浏览器中，不需要注册账号。
- 采用静态网站方式发布，访问轻量、加载快速、维护成本低。

## 使用说明

- 进入在线平台后，可从左侧目录选择任意章节开始学习。
- 在顶部搜索框输入关键词，可快速查找对应课程内容。
- 完成章节后点击“标记为已学习”，平台会自动更新学习进度。
- 练习题提交后会显示正确答案及答题提示。
- 夜间阅读时，可使用页面顶部的主题切换按钮。
- 学习记录仅保存在当前浏览器；清除浏览器站点数据后，相关记录也会被清除。
